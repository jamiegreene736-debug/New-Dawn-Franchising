Integrate HeyGen AI video generation into the New Dawn Franchising CRM
and outreach agent. Dylan has an existing HeyGen avatar trained on his
likeness and voice. The system can generate short personalised video
messages from Dylan's avatar for individual leads and deliver them via
email or SMS. Both the AI agent and Dylan manually can trigger video
generation from any lead record.

---

## OVERVIEW

HeyGen allows the creation of personalised AI avatar videos using a
pre-trained avatar of Dylan. The integration works as follows:

1. A video script is generated by OpenAI — personalised to the lead
2. The script is submitted to the HeyGen API with Dylan's avatar ID
3. HeyGen renders the video (typically 2-5 minutes)
4. The system polls for completion and stores the video URL
5. The video is delivered to the lead via their chosen channel
   (email or SMS) with a personalised message wrapping the video
6. Delivery is included in the daily brief for approval like all
   other outreach — nothing sends without Dylan's explicit approval

## PART 1 — HEYGEN API INTEGRATION (backend)

Install dependencies:
  npm install axios form-data

HeyGen uses a REST API. Base URL: https://api.heygen.com

Build a dedicated heygen.service.ts with these functions:

async function generateVideo(script, avatarId, voiceId):
  POST https://api.heygen.com/v2/video/generate
  Headers: X-Api-Key: process.env.HEYGEN_API_KEY
  Body: {
    video_inputs: [{
      character: {
        type: "avatar",
        avatar_id: process.env.HEYGEN_AVATAR_ID,
        avatar_style: "normal"
      },
      voice: {
        type: "text",
        input_text: script,
        voice_id: process.env.HEYGEN_VOICE_ID,
        speed: 1.0
      },
      background: {
        type: "color",
        value: "#ffffff"
      }
    }],
    dimension: { width: 1280, height: 720 },
    aspect_ratio: "16:9",
    test: false
  }
  Returns: { video_id: "xxx" }
  Store video_id in DB with status = "rendering"

async function pollVideoStatus(videoId):
  GET https://api.heygen.com/v1/video_status.get?video_id=[videoId]
  Returns: { status: "processing" | "completed" | "failed",
             video_url: "...", thumbnail_url: "..." }
  Called by a polling job (see cron section)

async function listAvatars():
  GET https://api.heygen.com/v2/avatars
  Used in settings to let Dylan confirm his avatar ID is correct
  Returns list of available avatars with names and IDs

async function listVoices():
  GET https://api.heygen.com/v2/voices
  Used in settings to let Dylan confirm his voice ID is correct

Error handling:
- If HeyGen API returns an error, log it, update video status to
  "failed", notify Dylan via Slack, do not send the video
- If rendering takes longer than 30 minutes, mark as "timed_out"
  and notify Dylan

## PART 2 — VIDEO SCRIPT GENERATION (OpenAI)

Each video script is generated by OpenAI and personalised to the
specific lead. Scripts are short — HeyGen videos work best between
30 and 90 seconds. That translates to roughly 75-200 words of script.

OPENAI SYSTEM PROMPT FOR VIDEO SCRIPTS:
"You are writing a short personalised video script for Dylan to
record as an AI avatar video using HeyGen. Dylan is a franchise
consultant at New Dawn Franchising (newdawnfranchising.com).

The video will be sent directly to the lead as part of their
outreach sequence. It should feel like a genuine personal video
message from Dylan — warm, direct, and specific to the recipient.
Not a sales pitch. A human moment.

Script rules:
- Maximum 150 words (ideal is 90-120 words)
- Open with the lead's first name directly: 'Hey [Name],'
- Reference one specific thing about them or their situation
  (use the research dossier data provided)
- One or two sentences about how New Dawn Franchising could help
- Single clear CTA: book a quick call via the Calendly link
  (write '[CALENDLY LINK]' as a placeholder — it will be
  inserted in the email/SMS wrapper, not spoken in the video)
- Close warmly as Dylan
- Write naturally for spoken delivery — short sentences,
  no jargon, no buzzwords, no bullet points
- Never mention that this is an AI-generated video
- Never make promises about visa outcomes (legally prohibited)
- Never claim to be human if sincerely asked"

USER PROMPT:
"Write a personalised HeyGen video script for this lead:
Name: [firstName]
Company: [company]
Country: [country]
Score: [aiScore] — [tier]
Research summary: [researchDossier.summary]
Recent activity: [researchDossier.recentActivity]
Sequence touch: [touchNumber]
Previous outreach: [summary of what has been sent before]"

## PART 3 — DELIVERY CHANNEL SELECTION

When a video is triggered (by the AI agent or Dylan manually),
the sender chooses the delivery channel. This is presented as
a dropdown with three options:

  📧 Email (recommended)
    Sends a personalised email with the HeyGen video embedded
    as a thumbnail image that links to the video URL.
    Subject line is generated by OpenAI alongside the script.
    Best for: leads with a verified email, longer relationship,
    professional context.

  📱 SMS (via Twilio)
    Sends a short personalised SMS with the video URL.
    Best for: leads who have not replied to email, leads where
    a WhatsApp number is not available, warm leads who need a
    different touchpoint.
    SMS body: "Hey [Name], Dylan here from New Dawn Franchising —
    I recorded a quick personal message for you: [video URL]
    Reply STOP to opt out."

  💬 WhatsApp (via WhatsApp Business Cloud API)
    Sends the video as a WhatsApp media message using an
    approved template.
    Best for: leads who are already engaged on WhatsApp,
    international leads where WhatsApp is the primary channel.

DEFAULT RECOMMENDATION LOGIC (shown as a suggested badge in the UI):
- If lead has replied to email before → recommend Email
- If lead has not opened the last 2 emails → recommend SMS
- If lead is from UAE, India, or other WhatsApp-primary markets
  AND has a phone number → recommend WhatsApp
- Otherwise → default to Email

The dropdown shows the recommended option pre-selected with a
small "Recommended" badge, but the user can always change it.

## PART 4 — TRIGGERING A VIDEO (two ways)

### WAY 1 — AI AGENT AUTOMATED TRIGGER

The agent can include a video in the daily batch under specific
conditions. Include a HeyGen video recommendation in the daily
brief when:

  Condition A — Warm lead, no reply after Touch 2:
    Lead scored 60+ who has not replied after 2 email touches.
    A personalised video as Touch 3 instead of a plain email
    has significantly higher engagement.

  Condition B — HOT lead first contact:
    Lead scored 85+ on discovery. Skip the plain cold email
    and lead with a video message instead.

  Condition C — Post-consultation follow-up:
    Lead completed a Zoom call but has not signed. A personal
    video message 48 hours after the call as a warm nudge.

When the agent recommends a video, include it in the daily brief
under a dedicated section:

  🎬 HEYGEN VIDEO RECOMMENDATIONS
  ─────────────────────────────────
  Videos are generated now and ready to send on your approval.
  Review each video in the portal before approving.

  V1. Ahmed Al-Rashid [Score: 84 🔴 HOT] — First contact video
      Channel: WhatsApp (recommended — UAE lead)
      Script preview (first 2 lines):
      "Hey Ahmed, I came across your work at Al-Rashid Group and
       wanted to reach out in a more personal way..."
      Duration: ~45 seconds | Status: ✅ Rendered
      [Preview video in portal] [Change channel] [Skip]

  V2. Sarah Mitchell [Score: 71 🟠 WARM] — Touch 3 video
      (no reply after 2 emails)
      Channel: Email (recommended)
      Script preview: "Hey Sarah, I know inboxes get busy —
       I wanted to try something a little different..."
      Duration: ~38 seconds | Status: ⏳ Rendering (est. 2 min)
      [Preview video in portal] [Change channel] [Skip]

  Reply YES to approve all outreach including these videos.
  Reply "SKIP VIDEO #V1" to exclude a specific video.
  Videos are only sent after your approval — same as all outreach.

IMPORTANT: Videos are generated during the 6 AM preparation run
so they are fully rendered by the time the 7 AM brief is sent.
Never include a video in the brief that has not finished rendering.
If rendering fails before 7 AM, exclude from the brief and note it:
"V1 failed to render — excluded from today's batch. Retry in portal."

### WAY 2 — MANUAL TRIGGER FROM LEAD RECORD

On any lead record in the CRM, add a "Send Video" button in the
outreach actions panel. This allows Dylan to generate and send a
video to any lead at any time outside of the automated sequence.

"Send Video" button opens a side panel with:

  Step 1 — SCRIPT
  Show the AI-generated script (auto-generated on panel open)
  Large editable text area — Dylan can edit every word before
  generating the video. Character count shown. Word count shown.
  Estimated video duration shown (calculated at ~130 words/min)
  "Regenerate script" button (calls OpenAI again with a different angle)
  "Use this script →" button to proceed

  Step 2 — CHANNEL
  Dropdown: Email / SMS / WhatsApp
  Pre-selected based on recommendation logic
  Shows lead's email address and/or phone number for confirmation
  "Recommended: [channel]" badge on the suggested option

  Step 3 — PREVIEW & SEND
  "Generate Video" button — calls HeyGen API with the script
  While rendering: show a progress indicator with estimated time
  When complete: show a video thumbnail with a play button
  Dylan can watch the full video before approving
  "Approve & Send Now" button — sends immediately (no daily brief)
  "Add to Tomorrow's Brief" button — queues for next daily batch
  "Discard" button — cancels without sending

Manual sends triggered from the lead record are logged immediately
to the activity timeline without going through the daily brief —
these are direct sends that Dylan has manually reviewed and approved
in real time.

Add a "Videos" section to every lead record showing all videos
generated and sent for that lead.

VIDEO ENTRY SHOWS:
- Thumbnail (from HeyGen thumbnail_url)
- Script text (expandable)
- Channel sent on (email / SMS / WhatsApp)
- Date generated / date sent
- HeyGen render status (rendering / completed / failed)
- Delivery status (sent / delivered / opened / clicked / replied)
- Video engagement: was the video link clicked? (tracked via
  a redirect URL that logs the click before forwarding to HeyGen)
- "Watch video" button (opens in a modal player or new tab)
- "Resend" button (resends the same video to the same lead
  — shows a confirmation prompt)
- "Use script as template" button (saves this script as a
  reusable template for similar leads)

VIDEO CLICK TRACKING:
When a video URL is generated, wrap it in a tracking redirect:
  https://[app-domain]/v/[unique-token]
  This route logs the click (lead ID, timestamp, device type)
  then immediately redirects to the actual HeyGen video URL.
  This gives open/click data for video messages the same way
  email open tracking works.

## DATABASE ADDITIONS

model HeyGenVideo {
  id                String   @id @default(cuid())
  leadId            String
  franchiseeId      String?
  script            String
  heygenVideoId     String?
  status            String   @default("pending")
  // pending → rendering → completed → failed → timed_out
  videoUrl          String?
  thumbnailUrl      String?
  trackingToken     String   @unique @default(cuid())
  trackingUrl       String?
  deliveryChannel   String?
  // email / sms / whatsapp
  deliveryStatus    String   @default("not_sent")
  // not_sent → sent → delivered → clicked → replied
  sentAt            DateTime?
  clickedAt         DateTime?
  renderStartedAt   DateTime?
  renderCompletedAt DateTime?
  renderDurationSec Int?
  dailyBatchId      String?
  scriptTemplateId  String?
  createdAt         DateTime @default(now())
  updatedAt         DateTime @updatedAt
}

model HeyGenScriptTemplate {
  id          String   @id @default(cuid())
  label       String
  script      String
  touchType   String?
  useCount    Int      @default(0)
  createdAt   DateTime @default(now())
}

model HeyGenSettings {
  id               String   @id @default(cuid())
  avatarId         String
  voiceId          String
  defaultChannel   String   @default("email")
  speakingSpeed    Float    @default(1.0)
  bgColour         String   @default("#ffffff")
  dailyVideoLimit  Int      @default(5)
  autoHotLeads     Boolean  @default(true)
  autoTouch3       Boolean  @default(true)
  autoPostCall     Boolean  @default(true)
  updatedAt        DateTime @updatedAt
}

## CRON ADDITIONS

Add to the 6 AM preparation run:
  - Query leads that meet the auto-trigger conditions
  - For each qualifying lead (up to daily limit):
    1. Generate script via OpenAI
    2. Submit to HeyGen API → get video_id back
    3. Store in HeyGenVideo with status = "rendering"
  - Poll all rendering videos every 2 minutes until complete
    or until 6:55 AM (must be done before the 7 AM brief)
  - Any video still rendering at 6:55 AM is excluded from
    the brief with a note

Add a separate polling job running every 3 minutes (all day):
  - Query all HeyGenVideo records with status = "rendering"
  - Call HeyGen status endpoint for each
  - Update status to "completed" or "failed" as appropriate
  - For "completed": store videoUrl and thumbnailUrl
  - For "failed": notify Dylan via Slack

## TRACKING REDIRECT ENDPOINT

GET /v/:trackingToken
  - Find HeyGenVideo by trackingToken
  - Log the click: update clickedAt, deliveryStatus = "clicked"
  - Add "video_clicked" entry to lead's activity timeline
  - 302 redirect to the actual video_url from HeyGen
  - If token not found: 404

## COMPLIANCE & CONSENT NOTES

- Dylan is the business owner and has created his own HeyGen
  avatar using his own likeness and voice — this is a fully
  consented use of the technology
- All video messages are sent as outreach from Dylan to leads
  who have been identified as potential clients — same legal

  the follow-up human response from Dylan should be honest
  about the technology used — build a note in the CRM flagging
  this question if it comes up in a reply

## IMPORTANT BUILD NOTES

- HeyGen rendering takes 2-5 minutes per video — never block
  the UI waiting for it. Use async polling with a progress
  indicator. The "Send Video" panel should show a live
  rendering progress bar with estimated time remaining.

- Always let Dylan preview the video before it sends —
  the "Approve & Send Now" path on the manual trigger MUST
  show the rendered video first. Never auto-send a video
  Dylan has not watched.

- Video tracking URLs must be unique per send — if the same
  video is resent, generate a new tracking token so clicks
  are attributed correctly to the right send event

- Keep video scripts under 150 words — HeyGen avatar quality
  drops on very long scripts and viewer drop-off increases
  sharply after 90 seconds

- Show estimated HeyGen cost per video on the generation UI
  ($0.10-0.30 per video depending on plan) and running
  monthly total in Reports so Dylan can monitor spend

- If HeyGen API is down during the 6 AM run, skip all video
  generation for that day, note it in the brief:
  "🎬 Video recommendations unavailable today — HeyGen API
  unreachable. Will retry tomorrow."

- Build full demo mode with 3 sample rendered videos (use
  placeholder video URLs), sample click tracking data, and
  a sample daily brief showing the video recommendations section
