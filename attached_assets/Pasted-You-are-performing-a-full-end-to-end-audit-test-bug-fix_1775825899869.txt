Before testing features, verify the foundation is solid:

1. ENV VARIABLES
   - Confirm all required .env variables are present and not empty:

     APOLLO_API_KEY (or HUNTER_API_KEY)
     NOTIFICATION_EMAIL
   - Flag any that are missing or using placeholder values
   - Do NOT expose values in logs — confirm present/absent only

2. DATABASE INTEGRITY
   - Confirm all required tables exist with the correct schema:
     tasks, email_log, leads, lists, list_members, campaigns, campaign_steps, outreach_log, campaign_metrics
   - Run a schema diff against the expected column definitions from the original build prompts
   - Flag any missing tables, missing columns, incorrect data types, or missing indexes
   - Add any missing indexes on frequently queried columns: lead_id, campaign_id, status, sent_at, next_run
   - Check for orphaned records: outreach_log rows with no matching lead, campaign_steps with no matching campaign
   - Fix all schema issues in place — do not drop and recreate tables, migrate safely

3. SERVER HEALTH
   - Confirm the Express server (or existing backend) starts without errors
   - Confirm all API routes are registered and reachable
   - Test every API endpoint with a basic request and confirm it returns the correct HTTP status code
   - Identify any routes that return 500 errors, undefined responses, or crash the server
   - Fix all broken routes

4. SCHEDULER HEALTH
   - Confirm node-cron (or equivalent) is initialised and all jobs are registered
   - Log all registered cron jobs with their schedule expression and next run time
   - Verify no duplicate jobs are registered (can happen after hot reloads)
   - Confirm the scheduler survives a server restart without double-registering jobs
   - Fix any duplicate registration or missed job issues

5. FRONTEND BUILD
   - Confirm the portal loads without console errors
   - Check for any broken imports, missing components, or failed API calls on page load
   - Verify all UI panels render correctly: SEO Tasks panel, Lead Pipeline panel, Lists Manager, Campaigns Dashboard, Activity Feed, Search & Discover
   - Confirm the layout is correct on both desktop and mobile viewports
   - Fix all rendering errors and layout breaks
