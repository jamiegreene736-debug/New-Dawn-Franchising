CAMPAIGN LIST BUILDING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

The agent must be able to research, compile, and manage contact lists that are used to power outreach campaigns. Lists are the foundation of every campaign — no campaign should launch without a vetted list attached to it.

LIST BUILDING PROCESS:

Step 1 — DEFINE the list
The user specifies (or the agent suggests) a target segment. Examples:
- "E-2 visa attorneys in California — top 50 firms"
- "Franchise brokers nationwide who have listed E-2 eligible franchises"
- "International relocation consultants in Texas and Florida"
- "Immigration law firms in New York with 10+ attorneys"

Step 2 — RESEARCH the list
The agent searches across web sources, directories, LinkedIn, and business databases to find qualifying contacts. For each contact found, it attempts to enrich with email, phone, mailing address, and LinkedIn URL using Apollo.io, Hunter.io, or ZoomInfo (whichever is configured).

Step 3 — SCORE & FILTER the list
Apply the lead scoring logic (1–10). By default, only include contacts scoring 6 or above in a campaign list. Allow the user to override the threshold.

Step 4 — DEDUPLICATE
Before saving, check the list against all existing leads in the database. Flag duplicates. Do not create duplicate records — instead, link the existing lead to the new list.

Step 5 — SAVE & NAME the list
Save the list with a user-defined name, creation date, segment tag, and the total number of contacts. Example: "E-2 Attorneys CA — Built 2024-06-01 — 47 contacts"

Step 6 — REVIEW & APPROVE
Present the list to the user in the portal for review before it is used in any campaign. Show a summary table with name, title, company, score, and available contact channels. Allow the user to remove individual contacts before approving.

LIST TYPES:
- Cold List: No prior contact — brand new leads
- Warm List: Leads who have previously opened an email, clicked a link, or replied
- Re-engagement List: Leads who went cold after the initial sequence (21+ days no response)
- VIP List: Leads scored 9–10 — eligible for all channels including physical mail and HeyGen video
- Partner List: Confirmed referral partners who have agreed to work with New Dawn Franchising

LIST MANAGEMENT RULES:
- A lead can exist on multiple lists but should never receive duplicate messages within the same campaign
- Lists must be refreshed and re-enriched every 90 days automatically
- Archive lists that have not been used in 180 days
- Track list performance: total contacted, open rate, reply rate, conversions per list

CAMPAIGN ENGINE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

The agent must be able to create, launch, monitor, optimize, and retire campaigns. A campaign is a structured outreach effort targeting a specific list with a defined sequence of messages across one or more channels.

─────────────────────────────────────────
CREATING A NEW CAMPAIGN
─────────────────────────────────────────

When the user asks to create a campaign (or the agent proactively suggests one based on a new list), the agent must:

1. Ask for (or infer from context):
   - Campaign name
   - Target list (select from saved lists)
   - Primary goal: Awareness / Meeting Booked / Referral Agreement Signed
   - Channels to use: Email / SMS / WhatsApp / Physical Mail / HeyGen (optional)
   - Start date and end date (or run until list is exhausted)
   - Daily send limits per channel

2. Generate a full campaign sequence automatically based on best practices for the target segment. Example for Immigration Attorneys:
   Day 1  — Email: Introduction + FDD offer
   Day 3  — SMS: Friendly nudge
   Day 5  — WhatsApp: Template message with link
   Day 8  — Email: Social proof / case study angle
   Day 12 — Email: Different value angle (focus on client benefit, not product)
   Day 16 — Physical Mail: Premium letter (VIP list only)
   Day 20 — Email: Final outreach / break-up message

3. Generate all message copy automatically for each step in the sequence. Personalize by referral category (attorneys get different copy than franchise brokers). Present all copy to the user for review and editing before the campaign launches.

4. Require user approval before activating. No campaign launches without explicit portal confirmation.

─────────────────────────────────────────
CAMPAIGN MONITORING
─────────────────────────────────────────

Once a campaign is live, track in real time:
- Total contacts in campaign
- Messages sent / delivered / opened / clicked / replied (per channel)
- Contacts who have replied — flag immediately and pause their sequence
- Contacts who have unsubscribed or opted out — remove from all active campaigns
- Contacts who have bounced (invalid email/phone) — flag for manual review
- Conversion events: meeting booked, referral agreement sent, partnership confirmed

Display all metrics on the Campaign Dashboard inside the portal.

─────────────────────────────────────────
CAMPAIGN OPTIMIZATION
─────────────────────────────────────────

The agent continuously analyzes live and completed campaigns and suggests or automatically applies optimizations. Optimization logic includes:

A/B SUBJECT LINE TESTING
- For every email campaign with 20+ contacts, automatically split the list 50/50 and test two subject line variants
- After 48 hours, measure open rates and declare a winner
- Automatically send all remaining contacts the winning subject line
- Log the winning variant and apply it as the default for future campaigns targeting the same segment

SEND TIME OPTIMIZATION
- Track open and reply rates by day of week and time of day
- After 3 campaigns, identify the best-performing send windows per channel per segment
- Automatically adjust future campaign send times to match peak engagement windows
- Default best practice until enough data exists: Email at 9 AM local time Tuesday–Thursday, SMS at 10 AM, WhatsApp at 11 AM

MESSAGE COPY OPTIMIZATION
- After each campaign completes, score every message step by its reply rate
- Flag any step with a reply rate below 1% as underperforming
- Generate 2 alternative copy variants for underperforming steps using the AI agent
- Present them to the user for selection, or auto-apply the agent's top recommendation if the user has enabled auto-optimize mode

SEQUENCE LENGTH OPTIMIZATION
- Track at which step in the sequence most replies occur
- If 80% of replies happen in steps 1–4, suggest shortening the sequence
- If engagement drops to zero after step 3 for a particular segment, recommend pausing remaining steps and switching to a re-engagement campaign instead

CHANNEL PERFORMANCE RANKING
- After every campaign, rank channels by cost per reply (factoring in API costs where applicable)
- Surface this ranking in the portal so the user can shift budget and effort toward the highest-performing channels

LIST QUALITY SCORING
- After each campaign, score the source list by response rate and conversion rate
- Recommend list refresh, scoring threshold adjustment, or segment refinement if performance is below benchmark
- Benchmark targets: Email open rate 25%+, reply rate 3%+, meeting booked rate 1%+

PROACTIVE CAMPAIGN SUGGESTIONS
- If the agent detects that a saved list has not been used in 30+ days, suggest launching a campaign against it
- If a re-engagement list grows beyond 20 contacts, suggest a re-engagement campaign automatically
- If a competitor is detected adding new referral partners (via competitor monitoring), immediately suggest a campaign targeting that same partner category
- Surface all suggestions in the portal as actionable cards: "🚀 Suggested: Launch E-2 Attorneys CA Campaign — 47 contacts ready"
