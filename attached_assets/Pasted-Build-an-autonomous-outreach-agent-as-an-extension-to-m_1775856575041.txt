Build an autonomous outreach agent as an extension to my existing New Dawn Franchising / VisaFranchise CRM. The agent's single job: given a target persona and a weekly booked-meeting goal, it should find leads, warm them up across email / WhatsApp / LinkedIn / forums, and book qualified Zoom calls on Dylan's calendar — speaking as Dylan in a warm, first-person voice. It runs daily, logs everything, and pauses to ask me when it needs credentials, approval, or budget.

==================================================
CORE CONCEPT
==================================================
I define campaigns like: "Book 5 qualified Zoom calls per week with immigration attorneys in the UAE who serve E-2 visa clients." The agent then runs a daily cron that sources leads, scores them, drafts personalized multi-channel touches, queues them for my approval (or auto-sends if I've enabled it for that channel), tracks replies, and iterates. Every action is logged and every outbound message is CAN-SPAM / GDPR / WhatsApp Business Policy compliant.

==================================================
THE DAILY AGENT LOOP
==================================================
For each active campaign, once per day:

1. SOURCE: Pull new leads matching the persona from Apollo (primary) and any configured Apify actors. Deduplicate against existing contacts. Cap new leads per day per campaign (default 50) to keep volume sane.

2. SCORE: For each new or stale lead, compute a 0–100 score. Factors: persona match strength, seniority, firm size/prestige, geographic fit, recency of relevant activity (LinkedIn posts, published articles, firm news), and whether they serve E-2 visa clients specifically. Claude generates the score with a rationale; store both.

3. PLAN: Call Claude Sonnet 4.6 as the outreach strategist (system prompt below). Pass it: campaign goal, last 7 days of meetings booked, reply rates per channel, leads in each sequence stage, and today's top-scored leads. It returns a JSON array of today's actions — which leads to enter which sequences, which channel to use first, which replies need handling, which sequences to pause.

4. EXECUTE: Dispatch each action:
   - draft_first_touch → Claude writes a personalized first message as Dylan, grounded in something specific about the lead (recent post, firm specialty, shared connection). Saves as a touch with status="awaiting_approval" unless auto-send rules allow.
   - draft_follow_up → Contextual follow-up referencing prior touches and any opens/clicks.
   - handle_reply → Claude reads the reply, classifies sentiment (interested / objection / unsubscribe / out-of-office / cold), drafts a response, and updates the sequence. Positive replies ALWAYS surface to me before sending the meeting-booking message.
   - book_meeting → When a lead signals interest, send the Calendly link with a warm handoff message in Dylan's voice.
   - draft_forum_engagement → Find a thread where the lead asked a relevant question. Draft a GENUINELY helpful answer (not a pitch) with a soft signature. Always requires my approval — never auto-posts.
   - draft_linkedin_message → Writes the DM text and pushes it to my "LinkedIn queue" for me to send manually from my own account.
   - pause_sequence → For unsubscribes, bounces, clear no's.

5. CRITIQUE: End-of-day, Claude reviews: which channels/personas/message angles are producing replies and meetings, which are dead, what to change tomorrow. Writes a retro to the campaign log and adjusts the next day's plan context.

6. BLOCKER CHECK: If the planner needs something it doesn't have (Apollo credits depleted, WhatsApp template not approved, new geo needs local compliance review), it creates a blocker instead of failing.

==================================================
THE PLANNER SYSTEM PROMPT
==================================================
"You are Dylan's head of outreach at New Dawn Franchising. Your only goal is to book qualified Zoom meetings with prospects who could realistically refer E-2 visa franchise clients to Dylan. You think like a sharp BDR who deeply respects the recipient's time and inbox.

Hard rules you will never break:
- Every message must be genuinely personalized with something specific about the recipient — no mail-merge-flavored fake personalization
- Every email must include a one-click unsubscribe and physical address (CAN-SPAM)
- WhatsApp first touches must use an approved Business template; free-form only after they reply
- No LinkedIn automation — draft only, human sends
- No forum posts that are thinly-veiled ads — only substantive help, signature optional
- No purchased/scraped lists from shady sources; Apollo or public web only
- Never impersonate Dylan in a way that could mislead on material facts; the voice is his, but the content must be truthful
- If a recipient asks to stop, the entire sequence pauses immediately across all channels

Given the campaign state, recent performance, and today's top leads, return a JSON array of actions: [{action_type, contact_id, channel, rationale, expected_impact, payload}]. Prioritize reply-generating activity over volume. Return ONLY valid JSON."

==================================================
THE VOICE-OF-DYLAN SYSTEM PROMPT (for message drafting)
==================================================
"You are writing as Dylan, founder of New Dawn Franchising. You will receive 5–10 samples of his real writing — study the cadence, sentence length, vocabulary, and warmth. Match it. Dylan writes like a human, not a marketer: short sentences, specific details, occasional dry humor, no corporate filler.

Banned phrases: 'I hope this email finds you well', 'reaching out', 'circle back', 'touch base', 'quick question', 'synergies', 'leverage', 'per my last email', 'just wanted to', any em-dash overuse, any 'It's not just X, it's Y' construction.

Every first touch must:
- Open with something specific to the recipient (a post, a case, a firm detail) — no generic opener
- State the reason for writing in one sentence
- Offer concrete value before asking for anything
- End with a low-friction ask (a reply, not a meeting) — meetings come in touch 2 or 3
- Include a real signature block with unsubscribe + mailing address
- Be under 120 words

Return JSON: {subject, body, personalization_hook, confidence_score, ymyl_flag}"

GUARDRAILS
==================================================
- Global send cap per day per channel (configurable; default: 40 emails, 15 WhatsApp, 0 LinkedIn auto-sends ever)
- Per-contact cooldown: no more than one touch every 3 days, max 5 touches per sequence
- Automatic suppression list: any unsubscribe, bounce, or "stop" reply blocks that contact from ALL future campaigns forever
- Reply detection via SendGrid inbound parse webhook + Twilio webhooks — updates sequence state in real time
- Every outbound email includes unsubscribe link + physical address
- WhatsApp only sends during recipient's local business hours (use contact timezone)
- Daily digest email to me: meetings booked, replies needing attention, drafts awaiting approval, blockers, top-performing messages
- Audit log: every sourced lead, every draft, every send, every reply — fully queryable
