Build a Paid Marketing section inside an existing marketing portal web app using React and Tailwind CSS. This is a single-page dashboard section accessible via the main navigation. Use only mock/placeholder data — no backend or API connections needed. The goal is a fully functional, polished UI that feels like a real SaaS product.

---

TECH STACK
- React (functional components + hooks)
- Tailwind CSS for all styling
- Lucide React for icons
- No external data fetching — all data is hardcoded as mock arrays/objects in the component

---

PAGE STRUCTURE & LAYOUT

The page should have:
- A top header bar with the title "Paid Marketing", a subtitle "Manage your campaigns and discover new growth channels", and a blue "Add Campaign" button in the top right
- A summary stats row directly below the header showing 4 KPI cards: Total Monthly Spend, Total Leads Generated, Blended Cost Per Lead, and Active Campaigns count
- Three clearly labeled sections below that, separated by section headings with a thin divider line

GLOBAL DESIGN REQUIREMENTS

- Background: light gray (Tailwind gray-50)
- Cards: white background, rounded-xl, subtle shadow (shadow-sm or shadow-md)
- Primary accent: Blue (Tailwind blue-600)
- Secondary accent: Purple (Tailwind violet-600) for AI section
- Success/Active: Green (Tailwind green-500)
- Warning: Yellow (Tailwind yellow-400)
- Neutral/Paused: Gray (Tailwind gray-400)
- Font hierarchy: Large bold section headings, medium weight subheadings, regular weight body text, small gray metadata text
- All interactive elements (buttons, toggles, edit icons, bookmark icons, dropdowns) must be functional using React useState
- Fully responsive across desktop, tablet, and mobile breakpoints
- Smooth transitions on hover states for buttons and cards (transition-all duration-200)
- The entire dashboard should feel like a premium SaaS product — clean, spacious, and professional
