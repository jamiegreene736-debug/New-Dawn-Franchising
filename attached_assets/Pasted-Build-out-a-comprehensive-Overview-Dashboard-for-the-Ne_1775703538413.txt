## PART 1 — MARKETING PORTAL NAVIGATION RESTRUCTURE

The current portal navigation needs to be restructured. Pipeline must
be its own tab. Reports must be its own tab. Neither lives inside
the other.

CURRENT (broken):
Dashboard / Leads / Outreach / Reports (contains pipeline) / Settings

NEW STRUCTURE (correct):
├── Overview          ← the main dashboard (this build)
├── Pipeline          ← dedicated kanban + table view (own tab)
├── Leads             ← lead discovery, scoring, individual records

## PART 2 — OVERVIEW DASHBOARD (/marketing-portal/dashboard)

The Overview Dashboard is the first thing a franchisee sees when
they log in. It must answer the question "how is my business doing
right now?" in under 10 seconds. Every metric is real-time or
updated within the last 24 hours. No metric is filler.

The dashboard is divided into six visual zones stacked vertically:

  ZONE 1 — Daily Agent Status Bar (full width, top of page)
  ZONE 2 — Primary KPI Cards (top metrics row)
  ZONE 3 — Pipeline Health Row
  ZONE 4 — Outreach Performance Row
  ZONE 5 — Two-column section: Activity Feed + Upcoming Actions
  ZONE 6 — Mini Charts Row (trend sparklines)

---

### ZONE 1 — DAILY AGENT STATUS BAR (full width banner)

A slim status bar pinned just below the portal nav. Always visible.
Changes colour and content based on current agent state.

States and colours:
  PENDING (yellow): "⏳ Today's outreach brief is ready and waiting
  for your approval. [View & Approve Brief →]"

  APPROVED (blue, pulsing dot): "🔵 Agent is executing — X messages
  are being sent right now. [View Activity →]"

  EXECUTED (green): "✅ Done for today — X emails sent, X WhatsApp
  sent, X letters queued. [View Summary →]"

  HELD (grey): "⏸ Today's outreach was held. Nothing was sent.
  [Review in Outreach →]"

  NOT EXECUTED (red): "⚠️ Today's brief expired without approval.
  Messages have rolled over to tomorrow. [Review →]"

  NO BRIEF YET (neutral): "Agent is preparing today's brief.
  Check back at 7:00 AM."

The banner is always one click away from the relevant action.

### ZONE 2 — PRIMARY KPI CARDS (8 cards in a responsive grid)

Display these 8 metric cards in a 4x2 grid (desktop) or 2x4 (mobile).
Each card shows: metric name, current value (large), comparison delta
(vs last 7 days or last month), and a mini trend indicator (up/down arrow
with percentage change). Cards use colour-coded status: green = good,
amber = watch, red = needs attention.

CARD 1 — TOTAL ACTIVE LEADS
Value: Total number of leads currently in the pipeline
(excludes Cold tier and DNC)
Delta: "+X new this week"
Colour: neutral — informational
Click: goes to Pipeline page

CARD 2 — HOT LEADS 🔴
Value: Number of leads currently scoring 80+
Delta: "+X vs last week"
Colour: red accent — signals urgency
Click: goes to Pipeline filtered to HOT tier
Sub-line: "X have a verified address — letter ready"

CARD 3 — CONSULTATIONS BOOKED
Value: Total Zoom/call consultations booked this month
Delta: "+X vs last month"
Colour: green if above target, amber if below
Click: goes to bookings calendar
Sub-line: "Next call: [Date, Time] with [Lead First Name]"

CARD 4 — OUTREACH SENT TODAY
Value: Total messages sent today (emails + WhatsApp combined)
Delta: "X emails / X WhatsApp"
Colour: green if brief was approved, grey if not yet
Click: goes to Outreach sent log

CARD 5 — EMAIL OPEN RATE (last 30 days)
Value: Percentage displayed large (e.g. "42%")
Delta: "+X% vs last month"
Colour: green if above 35%, amber if 20-35%, red if below 20%
Click: goes to Reports — email performance

CARD 6 — REPLY RATE (last 30 days)
Value: Percentage of outreach emails that received a reply
Delta: "+X% vs last month"
Colour: green if above 8%, amber if 4-8%, red if below 4%
Click: goes to Reports — reply performance

CARD 7 — ACTIVE MANAGED PROPERTIES
Value: Number of homeowner properties currently under management
Delta: "+X added this month"
Colour: always green (positive metric)
Click: goes to a property portfolio view (future feature placeholder)
Sub-line: "X new signed this month"

CARD 8 — PIPELINE VALUE (estimated)
Value: Estimated monthly recurring revenue if all WARM and HOT
leads convert (based on average management fee × property count)
Delta: "+$X vs last week"
Colour: green
Formula shown on hover: "Based on X leads × avg $[fee]/mo"
Click: goes to Reports — revenue forecast
Note: Label clearly as "Estimated Pipeline Value" not confirmed revenue

### KANBAN BOARD VIEW

One column per pipeline stage. Columns are horizontally scrollable.

STAGES (left to right):
  New Lead | Contacted | Replied | Call Scheduled |
  Call Completed | Proposal Sent | Converted | Lost

Each column:
- Column header with stage name + lead count badge
- Estimated value for leads in this stage (sum of pipeline value)
- Cards are vertically scrollable within each column
- "Add lead to this stage" button at bottom of each column

Each lead card shows:
- Lead name (bold) and company/property count if known
- Score badge (number + tier colour dot)
- Lead source tag (small pill: Zillow / Apollo / Reddit / Referral etc.)
- Days in current stage (amber if 7+ days, red if 14+ days)
- Channel icons showing which outreach has been sent
  (email envelope / WhatsApp / letter icons, greyed out if not sent)
- Last activity line: "Opened email 2h ago" / "No activity 8 days"
- Quick action buttons on hover:
  👁 View record | ✉️ Draft email | 📞 Log call | ➡️ Move stage

Drag and drop cards between columns to change stage.
Stage change is instant and logged to the activity timeline.

Add a "Customise Dashboard" button in the top right of the Overview

- Reorder the six zones (drag to reorder)

## API ENDPOINTS NEEDED FOR DASHBOARD

GET /api/franchisee/dashboard/summary
  Returns all Zone 2 KPI card values for the logged-in franchisee
  Response includes: activeleads, hotLeads, consultationsBooked,
  outreachSentToday, emailOpenRate, replyRate, activeProperties,
  pipelineValue (estimated)

GET /api/franchisee/dashboard/pipeline-health
  Returns stage funnel counts, tier breakdown, velocity metrics

GET /api/franchisee/dashboard/outreach-performance
  Returns email, WhatsApp, letter, and approval stats (last 30 days)

GET /api/franchisee/dashboard/activity-feed?limit=20&offset=0
  Returns paginated activity feed entries for the franchisee

GET /api/franchisee/dashboard/upcoming-actions
  Returns prioritised action items grouped by urgency

GET /api/franchisee/dashboard/sparklines
  Returns 30-day daily data for all four sparkline charts

GET /api/franchisee/pipeline?stage=&tier=&source=&scoreMin=&scoreMax=
  Returns filtered pipeline leads for the Pipeline page

PATCH /api/franchisee/pipeline/:leadId/stage
  Updates a lead's stage (drag and drop kanban action)
  Body: { stage: "replied" }
  Logs a stage_change activity entry automatically

GET /api/franchisee/reports/:tab?from=&to=
  Returns data for each Reports tab with date range filtering

## IMPORTANT BUILD NOTES

- All dashboard data must be scoped to the logged-in franchisee only —
  never return data from another franchisee's account

- The daily agent status bar (Zone 1) is the most important UI element
  on the entire dashboard — make it impossible to miss and always
  one click away from taking action

- Pipeline value estimates must always be clearly labelled as
  estimated — never present projected revenue as confirmed

- The kanban drag-and-drop must work smoothly on both desktop
  and mobile (use a touch-friendly drag library)

- KPI card deltas should compare against the same period length:
  if showing last 7 days, compare against the 7 days before that.
  Never compare 7 days against a full month.

- Cards that have no data yet (new franchisee) should show a clean
  empty state with a helpful prompt rather than zeros:
  "No consultations yet — your first lead is waiting in Pipeline →"

- The activity feed should feel live — poll every 60 seconds and
  animate new entries sliding in from the top

- Pipeline value calculation: (number of HOT + WARM leads) ×
  (franchisee's configured average management fee) × (historical
  conversion rate for their tier — default to 15% if no history yet)
  Always show the formula on hover so the franchisee understands it

- Dashboard loads must be fast — use skeleton loading states on all
  zones so the page feels instant even before data arrives

- All charts use Recharts. Keep them clean — no chart junk,
  no unnecessary gridlines, data labels only where they add value

- Build the full demo mode with realistic fake data for all zones
  including a sample HOT lead, a consultation booked this week,
  a letter in transit, and 30 days of sparkline trend data
